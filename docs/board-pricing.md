## 0. 設計方針

- 22物件(土地)を Monopoly と同じ8色グループ・同じマス配置に割り当て、購入価格のみ **1〜38 unit** の範囲に圧縮する。
- 賃料(訪問者が飲むunit量)は物件ごとにハードコードせず、**価格に係数を掛ける共通の式**から算出する。実装時のデータ量を減らし、後からバランス調整しやすくするため。
- 建設費(店舗レベルアップ1回あたりのunit)は色グループ単位で固定値。
- 鉄道(Railroad)相当は「駅前コンビニ」、電力・水道(Utility)相当は「タクシー会社/送迎バス」に置き換え、Monopoly同様「所有軒数に応じて賃料が跳ね上がる」方式を維持。

### 賃料算出式(物件マスのみ)

```
土地のみ・単独所有   = round(価格 × 0.2)
土地のみ・グループ完全所有(店舗未建設) = round(価格 × 0.4)
Lv.1店舗            = round(価格 × 0.5)
Lv.2店舗            = round(価格 × 1.0)
Lv.3店舗            = round(価格 × 2.0)
Lv.4店舗            = round(価格 × 3.0)
最大レベル(コンプリート後の特別改装) = round(価格 × 4.5)
```
最小値は常に1 unit。四捨五入(0.5は切り上げ)。

> **注記:** 最上位色(ダークブルー系)の最大レベルは 130〜170 unit と高額になる。意図的な「終盤の一撃逆転」演出だが、実プレイでは過大な可能性があるため、プレイテスト後に係数(特に×3.0/×4.5)を下げる調整を推奨する。

## 3. ユーティリティ系マス

### コンビニ(鉄道相当、4マス: 5, 15, 25, 35)
- 購入価格: 各 **12 unit** 固定
- 訪問時飲酒量(所有軒数に応じる):

| 所有軒数 | 1軒 | 2軒 | 3軒 | 4軒(コンプリート) |
| --- | --: | --: | --: | --: |
| 飲酒量 | 2 | 4 | 8 | 16 |

- **演出(フレーバー):** 4軒とも「東口/西口/南口/北口」という同一チェーンの支店という設定。訪問時のログ表示は「〇〇(訪問者)は△△コンビニでレジ横のチューハイを買わされた → N unit」のような軽いテキストにする。4軒コンプリート時は「駅前を完全制圧」の演出バナーを出す(実装は任意、MVPでは文言のみ差し替え可能な定数にしておけばよい)。
- モノポリー本来の「鉄道」らしさを残したい場合の代替案として、コンビニではなく「終電カウントダウン」演出(訪問するたびに残り終電時刻が進む)も検討可。今回は運用のシンプルさを優先しコンビニ案を採用。

### タクシー会社・送迎バス会社(電力/水道相当、2マス: 12, 28)
- 購入価格: 各 **10 unit** 固定
- 訪問時飲酒量(所有種類数に応じる):

| 所有数 | 1種類 | 2種類(独占) |
| --- | --: | --: |
| 飲酒量 | 3 | 8 |

- **演出(フレーバー):** モノポリー原典はサイコロの出目に応じて金額が変動するが、本ゲームは「1イベントの結果を毎回サイコロ計算させると進行が遅くなる」ため採用せず、固定値(3/8)とする。演出上は「タクシー会社(12番)」「送迎バス会社(28番)」を別会社として扱い、ログ表示を「タクシー代がかさんで一杯 → N unit」「送迎バスの運転手に一杯おごらされた → N unit」のように出し分ける。
- オプションルール案(MVP非採用・将来検討): 出目合計に応じて飲酒量を微増させる「サプライズ運賃」バリアント。導入する場合は `calcUtilityRent(baseValue, diceTotal)` のような関数を別途追加する形にし、コア計算式(3/8固定)は変えない。

## 5. 実装メモ(データ構造案)

物件マスはハードコードした賃料テーブルを持たせず、`price` と `colorGroup` だけを保持し、賃料は共通関数 `calcRent(price, level, isMonopolyOwned)` で算出する設計を推奨。

```ts
type SquareType =
  | "go" | "property" | "chance" | "communityChest"
  | "tax" | "railroad" | "utility" | "jail" | "freeParking" | "goToJail";

interface PropertySquare {
  id: number;              // 0-39
  type: "property";
  name: string;
  colorGroup: ColorGroup;  // "brown" | "lightblue" | ... | "darkblue"
  price: number;           // unit
}

const BUILD_COST_BY_GROUP: Record<ColorGroup, number> = {
  brown: 3, lightblue: 3, pink: 5, orange: 5,
  red: 7, yellow: 7, green: 9, darkblue: 9,
};

const RENT_MULTIPLIER = {
  landAlone: 0.2, landMonopoly: 0.4,
  lv1: 0.5, lv2: 1.0, lv3: 2.0, lv4: 3.0, max: 4.5,
} as const;

function calcRent(price: number, tier: keyof typeof RENT_MULTIPLIER): number {
  return Math.max(1, Math.round(price * RENT_MULTIPLIER[tier]));
}
```

コンビニ・ユーティリティ系は所有軒数がキーになるため、`price` 固定 + `ownedCount` から `RENT_TABLE[type][ownedCount]` を引く小さな固定テーブルで十分。
