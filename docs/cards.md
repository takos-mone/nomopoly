# チャンス・共同基金カード仕様

実装は `app/src/data/cards.ts`(カード定義)と `app/src/logic/cardEffects.ts`(効果エンジン)。
本ファイルはその内容を人間向けにまとめたもので、**コードを正とする**。

## 1. 抽選方式

カードは山札からランダムに1枚引かれるが、**カードごとの `weight` に比例した重み付き抽選**を行う。
同じカードを何枚も並べずに出現頻度だけ調整できるようにするための仕組みで、
バランス調整は `weight` の数値を変えるだけで済む(`weight` 省略時は1)。

出現確率 = そのカードの weight ÷ 山札全体の weight 合計。

## 4. 対象の決め方(`CardTarget`)

| target | 意味 |
| --- | --- |
| `currentPlayer` | カードを引いた本人 |
| `random` | 自分以外の生存者からランダムに1人 |
| `leftNeighbor` | 生存者の並びで見た左隣(脱落者は席を外している扱い) |
| `richest` | 所有物件数が最も多い生存者。**同数で並んだら該当者全員** |
| `poorest` | 所有物件数が最も少ない生存者。**同数で並んだら該当者全員** |
| `choose` | プレイヤーがモーダルで指名する |

- **脱落したプレイヤーはいかなる対象にもならない**。脱落ラインは「これ以上飲ませない」ための仕組みなので、
  漏らすと脱落済みの人に飲ませてしまう。
- `richest` / `poorest` は文面が「最も所有物件が多い/少ないプレイヤー」なので**自分自身も対象になりうる**
  (他の指名系と範囲が異なる点に注意)。
- 対象が1人も存在しない場合は例外を投げず「対象になるプレイヤーがおらず不発」とログして無効化する。

## 5. プレイヤーの選択が必要な効果

`GameState.pendingChoice` に積まれ、選ぶまでゲームは進まない。3種類ある。

| kind | 使う場面 | 選ぶもの |
| --- | --- | --- |
| `player` | あの人に一杯 / 連帯責任 / ジャンケン(相手) / 誕生日 / 多数決 | プレイヤー1人 |
| `duelOutcome` | ジャンケン / 街のお祭り | **実際に卓上でジャンケンして、勝った方** |
| `property` | 新メニュー | 無料改装する自分の物件 |

- ジャンケンは「相手を選ぶ → 実際に勝負 → 勝った方をタップ」の2段階。乱数では決めない。
- 新メニューは改装できる物件が1件しかない場合、選ぶ意味がないので確認を挟まず即適用する。
- 誕生日は、渡す側の残高が足りなければ持っている分だけ渡す(マイナスにはならない)。

## 6. 飲みの発生ルール

**カードで発生する飲みは、必ず飲み確認ポップアップを通る。**
「全員が飲む」系(`allDrink`)や「該当者全員」系も、内部で1人分ずつ(`drinkPlayer`)に展開してから
順番に確認を出す。まとめて加算すると確認・免除権・「今日は休み」・「倍プッシュ」がすべて無視されるため。

適用順は `createPendingDrink` に集約されている:

1. `outgoingMultiplier`(飲ませる側の「今夜は無礼講」)を適用
2. `incomingShield`(「今日は休み」)があれば全額無効化して終了
3. `incomingMultiplier`(「倍プッシュ」)を適用
4. 確定した量で確認ポップアップを出す(免除権を使うかどうかは本人が選ぶ)

なお**デュエルの敗者の飲みには `outgoingMultiplier` が乗らない**。勝負の結果であって
「自分が飲ませた」わけではないため、意図的にそうしている。

## 7. 移動系カードの扱い

- 移動後は着地マスの効果(飲み代・購入・税・カード)を**通常どおり連鎖解決する**。
- **前進でGOを跨いだ場合のみ**、サイコロで通過したときと同じ免除権が入る。
  後退でGOを通り過ぎた場合は「通過」ではないので入らない。
- 例外は2枚:
  - **直帰**: GOへ移動。跨いだかどうかに関係なく1周扱いで免除権が入る。
  - **職務質問**: タクシー待機所へ送られるが、GO通過扱いには**ならない**。
- カード→移動→着地→またカード、の連鎖には深さ上限(8)を設けている。
  現在の盤面では「寄り道で36→33(共同基金)」の1通りしか連鎖しないが、
  マスやカードを足したときに1手でゲームが固まるのを防ぐ保険。
