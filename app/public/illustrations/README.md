# 画像素材の置き場所

チャットに貼った画像はコードからファイルとして取り出せないため、
**この2ファイルを手動で保存してください。** 置いた瞬間からアプリに反映されます
(ファイルが無い間はイラストを描画せず、従来どおり絵文字だけで動きます)。

## 1. キャラクターのポーズ集

- 保存先: `app/public/illustrations/poses.png`
- 中身: 1枚目に貼った **4列×3行=12ポーズ** の画像を、**切り分けずにそのまま1枚**で保存
- 背景は透過PNGが理想(白背景でも動きますが、カードの上で白い四角が見えます)

コードは CSS スプライトとして12コマを切り出します。並び順は左上から右へ:

| | 1列目 | 2列目 | 3列目 | 4列目 |
| --- | --- | --- | --- | --- |
| **1行目** | `sitDrink` 座って一杯 | `cheer` 瓶を掲げて跳ねる | `sleepTable` 机で寝落ち | `chug` ラッパ飲み |
| **2行目** | `merryWalk` ごきげん歩き | `wooze` ふらふら | `faceDown` うつぶせ撃沈 | `sitBench` 縁側で一杯 |
| **3行目** | `dizzy` 頭を抱える | `collapsed` 仰向けダウン | `singing` 机でご機嫌 | `toast` 乾杯 |

グリッドの行数・列数を変えたい場合は `app/src/components/Illustration.tsx` の
`POSE_GRID` / `COLS` / `ROWS` を直してください。

### 使われている場所

| ポーズ | 表示場所 |
| --- | --- |
| `toast` | セットアップ画面のタイトル上 / 免除権などの獲得通知 / 勝利の結果画面 |
| `merryWalk` | マスに着地したときの説明 |
| `cheer` | チャンスカード / コイントスの表 |
| `sitDrink` | 共同基金カード |
| `sleepTable` | 強制移動の通知 / 休み中のパネル |
| `singing` | 一回休みの通知 |
| `collapsed` | 脱落の通知 |
| `dizzy` | コイントスの裏 |
| `faceDown` | 全員脱落の結果画面 |

## 2. アプリのアイコン

- 保存先: `app/public/icons/app-icon.png`
- 中身: 2枚目に貼ったロゴ画像
- サイズ: **512×512 px** の正方形PNG

`index.html` と `manifest.webmanifest` から参照済みです。
置かれていない間は既存の `favicon.svg` が使われます。
