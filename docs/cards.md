# チャンス・共同基金カード設計 + 飲み確認フロー

[decisions.md](./decisions.md) の「カード効果の重複ルールの詳細は未確定」を受けて、実装可能な形に具体化したドラフト。
実データは `app/src/data/cards.ts` を正とする(本ファイルはその設計サマリ)。

> **注意(2026-08-20 追記)**: 本ファイルは初期の設計ドラフトであり、以下の「簡略化した点」は
> その後のアップデートで**すべて解消済み**。現在の挙動は `app/src/` のコードと
> [decisions.md](./decisions.md) を正とする。差分は次のとおり:
>
> - 「好きな相手を指名」系は自動選択ではなく、**実際に対象を選ぶUI**(`TargetChoiceModal`)を実装済み。
> - 移動系カード(寄り道・常連)の着地マスは**連鎖解決する**(家賃・購入・カードドローが通常どおり発生)。
> - 「割引権」は「**免除権**」に改称し、自動消費をやめて**使うタイミングをプレイヤーが選ぶ**方式に変更。
> - カードは各16枚→**各24枚(合計48枚)**に増量。
> - 脱落したプレイヤーはあらゆる指名の対象から除外される。

## 0. 実装方針・簡略化した点

- 原案([requirements.md](./requirements.md) 15〜16章)の「好きな相手を指名」系は、対象選択UIを都度挟むと進行が重くなるため、**ランダム/ルールベースの自動選択**に簡略化した(例:「あの人に一杯」→ランダムな1人)。
- 「倍率」「特殊状態」系(倍プッシュ・今夜は無礼講・今日は休み)は、プレイヤーごとの一時フラグとして実装し、**次に発生する1回の飲みイベントにのみ**作用する(rent/tax/カードいずれにも共通適用)。
- 「移動系」カード(寄り道・常連)は、移動先での購入・家賃判定を連鎖させない(モノポリー本来は連鎖するが、UI・状態遷移の複雑化を避けるため今回は見送り)。
- 割引権(voucher)は、飲みイベント発生時に自動で優先消費される(このアップデートで初めて実際に機能するようになった)。

## 1. 飲み確認フロー(新機能)

家賃・税金・カード効果で「飲み」が発生するたびに、以下の順で自動処理される:

1. 倍率(outgoingMultiplier: 相手に飲ませる側の「今夜は無礼講」)を適用
2. シールド(incomingShield: 「今日は休み」)があれば全額無効化して終了
3. 倍率(incomingMultiplier: 「倍プッシュ」)を適用
4. 残額に対して割引権(voucherUnits)を自動消費
5. それでも残額があれば `pendingDrink` をセットし、確認ポップアップを表示してターン進行をブロック

ポップアップでの選択肢:

| 選択肢 | 効果 |
| --- | --- |
| 飲みきった! | 累計飲酒量に加算して終了 |
| 後で飲む(先送り) | プレイヤーの「先送りリスト」に積む。プレイヤー詳細モーダルからいつでも「今飲む」で精算可能 |
| 土地を抵当に入れる | 所有物件を1つ選んで抵当に。今回の飲みは免除されるが、その物件は家賃も改装も停止。返済時は**免除額の1.1倍**(端数切り上げ)を飲む必要がある |
| 交渉する | 所有物件を1つ選び、対象プレイヤーに譲渡。代わりにそのプレイヤーが同額を飲む(義務ごと転嫁) |
| 罰ゲームで代替する | 記録に一切残さず、その場の罰ゲームで代替したことにする(常に選択可能) |
